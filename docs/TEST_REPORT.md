# Отчёт о проверке · 21 октября 2026

## Окружение

- Windows x64, системная сборка 26200.
- Python 3.10.7 x64, Panda3D 1.10.16.
- pytest 9.1.1, PyInstaller 6.22.3.
- Python 3.11/3.12 рекомендованы для новой установки; в этом окружении они
  отсутствовали, поэтому фактический запуск на них не заявляется.

## Автоматические проверки

| Проверка | Результат |
|---|---|
| `python -m compileall -q main.py config.py game tests tools` | Успешно |
| `python -m pip check` | Несовместимых зависимостей нет |
| `python -m pytest -q` | **76 passed** |
| `python tools/smoke_test.py` | **32 проверки, 31 PNG**, успешно |
| `python tools/smoke_test.py --windowed` | Проверено настоящее окно и аудиодрайвер |
| PyInstaller onedir | Создана папка `dist/Snake3D` |
| `Snake3D.exe --offscreen --self-test` | Полная интеграционная проверка из EXE, код выхода 0 |

Логические тесты не импортируют Panda3D и не открывают окно. Проверяются:
движение, восемь вариантов относительного поворота, запрет разворота,
ограничение очереди поворотов, рост, все стены, тело, уходящий хвост,
препятствия, свободные клетки еды, заполненное поле и три цели победы.
Отдельно проверены JSON, отсутствующий/повреждённый профиль, неверные типы,
атомарная запись при ошибке, рекорды, сброс, награды и выбранная косметика.

**30 прохождений** трёх уровней (по десять случайных начальных состояний генератора)
выполнены поиском пути к реально созданной еде. Счёт и условия победы не подменяются.

Интеграционный сценарий регистрирует 30 реальных событий подбора за три мира,
проверяет открытие пяти достижений, аксессуары, повторную загрузку JSON,
блокировки меню, Esc, A/D, ползунки, паузу, проигрыш, R и повторный запуск.
Одна секунда движения при 30 и 144 FPS даёт одинаковые координаты.
Шесть циклов «игра → главное меню» не накапливают корни миров или мини-карты.

Рендеринг проверен в 1280×800, 800×900 и 1600×900. В обычном окне дополнительно
запрашиваются 900×700 и возврат к 1280×800. Для буфера без окна создаётся новый
буфер нужного размера: обычный offscreen-буфер Panda3D нельзя менять через `setSize`.

## Визуальная проверка

Просмотрены сохранённые кадры главного меню, выбора миров, кастомизации,
достижений, настроек, победы, игрового HUD, мини-карты, поворотов камеры и
положений у стен. Голова и тело видны, кириллица отображается, панели скруглены.
Встроенный Windows-рендерер успешно создал изображения, включая PNG из EXE.
Полный набор диагностических кадров и JSON находится в локальной папке `artifacts/`;
в Git включены только два небольших иллюстративных кадра в `docs/screenshots/`.

## Найдено и исправлено

1. Конфликт `restart` с жизненным циклом ShowBase — игровой метод переименован.
2. Нативный загрузчик не находил шрифт в абсолютном пути с кириллицей —
   ресурсы читаются Python и монтируются в память VFS.
3. Панели и кнопки с `relief=None` не имели фона — добавлены собственные
   скруглённые сетки; карта использует плоскую панель DirectGUI.
4. Noto Sans не содержал используемые символы стрелок — подсказки заменены
   текстовыми названиями, клавиши стрелок продолжают работать.
5. Порядок открытых наград отличался после загрузки — списки канонизируются.
6. Обработчик окна перекрывал стандартную обработку resize/close Panda3D —
   теперь вызывается базовый обработчик и сохраняется прогресс при закрытии.
7. Предпросмотр пересекался с панелью кастомизации — скорректированы масштаб и позиция.
8. Уведомления предыдущей сцены оставались в новом меню — добавлена очистка.
9. Камера показывала слишком мало тела — уменьшено смещение точки взгляда.
10. Деревья перекрывали голову у бортика — декорации на линии камера–голова
    временно скрываются; повторно просмотрены кадры у четырёх стен.
11. Начальная змейка на уменьшенном тестовом поле могла выходить за границу —
    исправлена начальная координата, добавлена проверка нескольких размеров.

## Ограничения и ручная приёмка

Известных критических ошибок по выполненным проверкам не осталось.
Обязательные механики реализованы. Фоновая музыка и установщик не добавлялись;
они не требуются для игры и запуска папочной сборки.

Рендеринг и вызовы аудиосистемы проверены автоматически, но качество звука
на слух, удобство реального управления и комфорт камеры нужно оценить человеку.
Проверка на другом Windows-компьютере без установленного Python не выполнялась.
Запрос 4× MSAA в offscreen-режиме даёт предупреждение о недоступном multisampling;
рендерер продолжает работать и сохраняет кадры. В обычном окне наблюдалось
предупреждение `SetForegroundWindow() failed`: система не разрешила программе
принудительно захватить фокус. Оно не мешало проверкам и рендерингу.
