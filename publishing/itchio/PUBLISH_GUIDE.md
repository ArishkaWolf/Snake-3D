# Публикация скачиваемой игры на itch.io

Материалы готовы; публичная страница itch.io этим набором не создаётся.
Для загрузки войдите в собственный аккаунт itch.io. Цена ниже — рекомендуемое
значение для лабораторной; владелец аккаунта может выбрать другое до публикации.

## Файлы

- Игра: `dist/Snake-3D-v1.1-Windows.zip` в репозитории или одноимённый файл из GitHub Releases.
- Название и параметры: `METADATA.json`.
- Описание для копирования: `PAGE_RU.md`.
- Поле Download instructions: `DOWNLOAD_INSTRUCTIONS.txt`.
- Обложка: `cover-1260x1000.png` (альтернатива `cover-630x500.png`).
- Пять изображений: `screenshots/01-garden.png`, `02-sand.png`, `03-lavender.png`,
  `04-customization.png`, `05-achievements.png`.

Обложки имеют соотношение 315:250. Скриншоты — 1280×800, без изменения игровых моделей
или интерфейса. На трёх игровых кадрах яблоко размещено в допустимой клетке перед
головой, чтобы показать еду. Обложка — отдельная композиция, отрендеренная самим
Panda3D из тех же моделей; она не является кадром игрового HUD.

## Шаги

1. Откройте [dashboard](https://itch.io/dashboard) и выберите **Create new game**.
2. Title: **Snake 3D — Маленькое путешествие**. Short description — из `METADATA.json`.
3. Classification: **Games**. Kind of project: **Downloadable**. Жанр: **Arcade**.
   Состояние: **Released**. Укажите только **Windows**, язык — **Russian**.
4. Для бесплатной учебной игры выберите **No payments**. Не настраивайте выплаты,
   если они не нужны для выбранной модели распространения.
5. Загрузите **Snake-3D-v1.1-Windows.zip**, отметьте платформу Windows.
   Это настольный EXE: пункт «This file will be played in the browser» не включайте.
   ZIP с пресс-китом не нужен в качестве основного скачиваемого файла.
6. Вставьте текст `PAGE_RU.md` в Description и оформите заголовки средствами редактора.
   В поле инструкции скачивания вставьте `DOWNLOAD_INSTRUCTIONS.txt`.
7. Загрузите обложку, затем пять скриншотов в указанном порядке.
8. Добавьте подходящие предложенные теги, например 3D, Snake, Cute, Cozy, Low-poly,
   Singleplayer. Если тег не предложен, используйте ближайший подходящий.
9. В AI Disclosure корректно укажите помощь генеративного ИИ в коде, текстах и композиции,
   выбирая соответствующие пункты текущей формы. В игре нет внешнего сервиса ИИ;
   геометрия и звуки создаются обычными алгоритмами. Изображения набора — рендеры игры.
10. Сохраните **Draft** через **Save & view page**. Скачайте файл со своей страницы,
    распакуйте и запустите EXE. Убедитесь, что название и загрузка отображаются верно.
11. Когда страница проверена, измените Visibility на **Public** и сохраните.

Вставлять пароль или токены в файлы набора не нужно.

Официальные инструкции, проверенные 21 октября 2026:
[создание страницы, размеры обложки и скачиваемые ZIP](https://itch.io/docs/creators/getting-started),
[правила качества, платформы и AI Disclosure](https://itch.io/docs/creators/quality-guidelines).
