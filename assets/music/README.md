# Little Journey · оригинальная фоновая композиция

48 секунд, 80 BPM, стерео PCM WAV 22050 Hz / 16 bit, бесшовная петля.
Спокойная инструментальная музыка с настроением пост-рока: щипковые струны,
стереозадержка, медленные пэды, бас и тихая перкуссия.

Музыка сочинена и синтезирована для Snake 3D. Сторонние записи и семплы не использованы.
Лицензия — MIT, как у проекта. Генератор использует только стандартную библиотеку:

```powershell
.\.venv\Scripts\python.exe tools/compose_music.py
```

Синтез выполняется при подготовке ресурса. Игра воспроизводит готовый файл через
отдельный музыкальный канал Panda3D. В настройках доступны независимые громкости
музыки и эффектов; при паузе музыка плавно приглушается.
